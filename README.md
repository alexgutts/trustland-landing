# TrustLand

A transparent and certified real estate platform connecting international investors with verified agents in Mérida, Yucatán.

## Features

- 🛡️ **Certified Agents Only** - Every agent verified by expert oversight
- ⭐ **Transparent Ratings** - 5-star review system like Airbnab for real estate
- 🏛️ **Mérida Focus** - Mexico's safest city with 15.6% annual property growth
- 🌍 **Bilingual** - Full English and Spanish support
- 📱 **Responsive** - Beautiful on all devices

## Getting Started

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Tech Stack

- **Framework:** Next.js 15
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Language:** TypeScript
- **Deployment:** Vercel (optimized)

## Deployment

Optimized for Vercel following cost-effective practices:

- Static rendering where possible
- Optimized images with Next.js Image
- Minimal JavaScript bundle
- Fast CDN delivery

Deploy with:

```bash
vercel
```
